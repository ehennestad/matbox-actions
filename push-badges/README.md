# Action for pushing GitHub badges
This action pushes generated badges to a target branch by copying badge files from the current workflow and committing them if changes are detected.

This action is used by MatBox workflows for branch-local badge updates after code analysis and code testing on `push` events or ready same-repository pull requests. It checks out the target branch, copies generated badge files from the workflow's `.github/badges` directory, and commits the updated badges back to that branch. The action only commits when actual changes are detected, preventing unnecessary commits.

Draft pull requests should not use this action to mutate the source branch. Ready pull requests can use it when the workflow intentionally keeps committed badge files current before merge.

## Usage
```yaml
- uses: ehennestad/matbox-actions/push-badges@v1
  with:
    # Branch reference to check out and push to
    pr-ref: ${{ github.ref_name }}

    # Repository in owner/repo format to check out from
    pr-repo: ${{ github.repository }}
```

> [!NOTE]  
> This action requires badges to be generated in `.github/badges` directory in previous workflow steps.

## Example
```yaml
name: Update Badges

on:
  push:
    branches: [ main, dev, 'release/**' ]
  pull_request:
    types: [opened, reopened, synchronize, ready_for_review]

jobs:
  test-and-update-badges:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
        
      - name: Setup MATLAB
        uses: matlab-actions/setup-matlab@v2
        
      - name: Install MatBox
        uses: ehennestad/matbox-actions/install-matbox@v1
        
      - name: Test Code
        uses: ehennestad/matbox-actions/test-code@v1
        with:
          create_badge: 'true'
          
      - name: Push Updated Badges
        if: ${{ github.event_name == 'push' || (github.event_name == 'pull_request' && !github.event.pull_request.draft && github.event.pull_request.head.repo.full_name == github.repository) }}
        uses: ehennestad/matbox-actions/push-badges@v1
        with:
          pr-ref: ${{ github.event_name == 'pull_request' && github.event.pull_request.head.ref || github.ref_name }}
          pr-repo: ${{ github.event_name == 'pull_request' && github.event.pull_request.head.repo.full_name || github.repository }}
```

This example illustrates how the action can be used to automatically update badges on stable branches and ready same-repository pull requests after running tests. The badges are generated by the test action and then pushed back to the branch being viewed.

## Features

- Checks out target branch in a separate working tree
- Copies generated badges from workflow to target branch
- Only commits when actual changes are detected
- Uses GitHub Actions bot for commits

## Inputs

| Input | Description |
|-------|-------------|
| `pr-ref` | [Required] Branch reference to check out and push badges to |
| `pr-repo` | [Required] Repository in owner/repo format to check out from |

## Outputs

This action does not produce outputs, but commits updated badge files to the specified target branch if changes are detected.

## Badge Update Process

The action follows this process:
1. **Checkout**: Creates a separate working tree for the target branch
2. **Copy**: Copies all badge files from `.github/badges` to the target branch
3. **Detect Changes**: Uses `git add --dry-run` to detect if any badges have changed
4. **Commit**: Only commits and pushes if changes are detected
5. **Clean Exit**: Gracefully handles cases where no badges exist or no changes are needed
