# Action for pushing GitHub badges
This action pushes generated badges to a pull request branch by copying badge files from the current workflow and committing them to the PR source branch if changes are detected.

This action is used by MatBox workflows for code analysis and code testing in pull requests. It checks out the source branch of a pull request, copies generated badge files from the workflow's `.github/badges` directory, and commits the updated badges back to the pull request branch. The action only commits when actual changes are detected, preventing unnecessary commits.

The motivation is to automatically update badges (such as test results, coverage, or other metrics) directly in pull request branches, ensuring that badge information is always current and visible in the repository without manual intervention.

## Usage
```yaml
- uses: ehennestad/matbox-actions/push-badges@v1
  with:
    # Branch reference to check out and push to
    pr-ref: ${{ github.head_ref }}

    # Repository in owner/repo format to check out from
    pr-repo: ${{ github.event.pull_request.head.repo.full_name }}
```

> [!NOTE]  
> This action requires badges to be generated in `.github/badges` directory in previous workflow steps.

## Example
```yaml
name: Update Badges

on:
  pull_request:
    branches: [ main ]

jobs:
  test-and-update-badges:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
        
      - name: Setup MATLAB
        uses: matlab-actions/setup-matlab@v2
        
      - name: Install MatBox
        uses: ehennestad/matbox-actions/install-matbox@v1
        
      - name: Test Code
        uses: ehennestad/matbox-actions/test-code@v1
        with:
          create_badge: 'true'
          
      - name: Push Updated Badges
        if: github.event_name == 'pull_request'
        uses: ehennestad/matbox-actions/push-badges@v1
        with:
          pr-ref: ${{ github.head_ref }}
          pr-repo: ${{ github.event.pull_request.head.repo.full_name }}
```

This example illustrates how the action can be used to automatically update badges in pull requests after running tests. The badges are generated by the test action and then pushed back to the pull request branch for immediate visibility.

## Features

- Checks out pull request source branch in separate working tree
- Copies generated badges from workflow to target branch
- Only commits when actual changes are detected
- Uses GitHub Actions bot for commits

## Inputs

| Input | Description |
|-------|-------------|
| `pr-ref` | [Required] Branch reference to check out and push badges to |
| `pr-repo` | [Required] Repository in owner/repo format to check out from |

## Outputs

This action does not produce outputs, but commits updated badge files to the specified pull request branch if changes are detected.

## Badge Update Process

The action follows this process:
1. **Checkout**: Creates a separate working tree for the pull request branch
2. **Copy**: Copies all badge files from `.github/badges` to the PR branch
3. **Detect Changes**: Uses `git add --dry-run` to detect if any badges have changed
4. **Commit**: Only commits and pushes if changes are detected
5. **Clean Exit**: Gracefully handles cases where no badges exist or no changes are needed
